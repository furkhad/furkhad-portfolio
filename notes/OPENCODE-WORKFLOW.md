You are reviewing a personal portfolio for Furkhad Ahmed. Read `AGENTS.md`, `README.md`, `public/index.html`, `public/assets/styles.css`, and `public/assets/script.js` before changing anything.

Task: perform a read-only audit first. Do not edit files on this pass. Report:
1. Broken links or inaccurate claims you can detect from the source.
2. HTML semantic and accessibility problems.
3. Responsive CSS risks, especially at 360px, 390px, 768px, and 1440px widths.
4. JavaScript behavior and possible edge cases.
5. SEO and sharing metadata problems.
6. A short, ordered list of only high-impact fixes.

Do not add frameworks, packages, tracking, new sections, visual effects, fabricated metrics, fake forms, or new project claims. Cite filenames and relevant snippets for each finding. Wait for approval before editing.

After the audit is approved, fix one issue at a time, explain why, run relevant checks, and show the diff.
