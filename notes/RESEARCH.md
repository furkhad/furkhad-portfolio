# Portfolio benchmark notes

The goal is not to copy any individual's layout. Borrow useful patterns and make the content and visual identity original.

## Sites to inspect

- Jagannath Nayak — https://portfjagannath.netlify.app/ — project filtering, timeline and credentials sections, 3D/WebGL treatment. Keep the useful information architecture; avoid making a heavy interactive intro the only way to reach the work.
- Brittany Chiang — https://britchiang.com/ — concise positioning, curated projects, résumé and repository links. Lesson: make work easy to find quickly.
- Anthony Fu — https://antfu.me/ — open-source work and tools used as concrete proof. Lesson: link technical claims to real artifacts.
- Bruno Simon — https://bruno-simon.com/ — portfolio-as-interactive-experience. Lesson: originality can demonstrate craft, but high-interaction navigation is not ideal as the only path for recruiter-facing content.
- Rauno Fäderholm — https://rauno.me/ — restrained design and details. Lesson: small interactions and typography can show polish without overwhelming content.
- Emil Kowalski — https://emilkowal.ski/ — UI behavior, open-source libraries, and motion as a craft signal. Lesson: interactive details should be intentional.
- Paco Coursey — https://paco.me/ — text-first clarity and writing. Lesson: a site does not need a large hero animation to work.
- Aditya Alok — https://www.adityaalok.dev/ — security/systems-specific dark design. Lesson: present the technical niche immediately, but avoid defaulting to a generic green-terminal aesthetic.
- CyberAsim — https://cyberasim.com/ — security career branding. Lesson: match the first-screen headline and project evidence to the intended security role.

## Design decision

Use a restrained editorial layout with a clear security identity, custom SVG/CSS project illustrations, readable case summaries, direct repository links, working filter controls, and no third-party trackers. Do not copy the referenced portfolio's visual assets, personal biography, exact layout, or code.
